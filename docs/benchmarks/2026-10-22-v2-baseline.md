# v2.1.0 performance baseline

- **Date:** 2026-10-22
- **Plan:** [2026-10-22-v3-rewrite](../plans/2026-10-22-v3-rewrite.md), step 1c "Benchmark and budgets"
- **Compare with:** the new-engine run in PR 11, which should use the same machine and method

## Summary
- v2 is smooth up to 500 confetti or emoji elements. At 2000 it still runs at about 110 fps, but the main thread is 68 to 80% busy, so the page has little room for anything else.
- Balloons do not scale. At 500 the animation drops to 35 fps, and at 2000 to 8.5 fps.
- v2's physics counts frames instead of time, so slow frames stretch the animation. The 10-second balloon burst took 17.5 s at 500 elements and 70 s at 2000.
- Script, style recalc and layout together are a small share of the cost. Most of the main-thread time is "other": paint, compositing and garbage collection. This is the per-node DOM cost that the v3 canvas renderer removes.

## Method
- The page renders one button and calls v2.1.0's `useReward('target', type, { elementCount })`. Every other option keeps its v2 default.
- The package is `react-rewards@2.1.0` from npm, with React 19.3.1, bundled by esbuild as a production build.
- Each combination of effect and element count runs in a fresh tab. The tab gets a 1.5 s settle delay, then one warm-up burst that is not recorded, then 3 recorded bursts. The tables show the median of the 3.
- A burst runs from the `reward()` call until `isAnimating` turns false. Frame timing comes from `requestAnimationFrame` timestamps over that window.
- Main-thread time comes from the Chrome DevTools Protocol `Performance.getMetrics`, read before and after each burst: `ScriptDuration`, `RecalcStyleDuration`, `LayoutDuration` and `TaskDuration`. "Other" is task time minus script, style and layout: mostly paint, compositing and garbage collection.
- Raster and GPU work on other threads is not included.
- Costs are given per v2 update. v2 advances its physics a fixed number of times per burst (`lifetime`: 200 updates for confetti and emoji, 600 for balloons) and never more than 60 times a second (`fps: 60`). At 120 Hz, every other animation frame therefore carries no update. When frames are slower than 60 fps, every frame carries one update and the burst takes longer than its nominal time.
- "Long frames" counts frames longer than 1.5 refresh intervals (12.45 ms).

## Harness
The harness ran from a scratch directory outside the repo. Its full source is below, so the run can be repeated. To recreate it, write these four files into an empty directory, then run `npm install`, `npx playwright install chromium` and `node run.mjs 3`. Keep the Chromium window uncovered while it runs, because macOS throttles windows that are hidden.

<details><summary><code>page/app.jsx</code></summary>

```jsx
import { useEffect, useRef } from 'react';
import { createRoot } from 'react-dom/client';
import { useReward } from 'react-rewards';

const params = new URLSearchParams(location.search);
const type = params.get('type');
const count = Number(params.get('count'));
const config = { elementCount: count };

function Bench() {
  const { reward, isAnimating } = useReward('target', type, config);
  const wasAnimating = useRef(false);
  window.__reward = reward;
  useEffect(() => {
    if (wasAnimating.current && !isAnimating) window.__onDone?.();
    wasAnimating.current = isAnimating;
  }, [isAnimating]);
  return (
    <div style={{ display: 'grid', placeItems: 'center', height: '100vh' }}>
      <button id="target" type="button">{`${type} × ${count}`}</button>
    </div>
  );
}

createRoot(document.getElementById('root')).render(<Bench />);

// Collects rAF timestamps from the reward() call until isAnimating turns false.
window.__run = () =>
  new Promise((resolve) => {
    const frames = [];
    let running = true;
    const tick = (t) => {
      frames.push(t);
      if (running) requestAnimationFrame(tick);
    };
    window.__onDone = () => {
      running = false;
      window.__onDone = null;
      resolve(frames);
    };
    requestAnimationFrame((t) => {
      frames.push(t);
      window.__reward();
      requestAnimationFrame(tick);
    });
  });

// Idle rAF interval, to find the display refresh rate.
window.__idle = (ms) =>
  new Promise((resolve) => {
    const frames = [];
    const tick = (t) => {
      frames.push(t);
      if (t - frames[0] < ms) requestAnimationFrame(tick);
      else resolve(frames);
    };
    requestAnimationFrame(tick);
  });
```

<details><summary><code>run.mjs</code></summary>

```js
// Baseline benchmark for react-rewards v2.1.0.
// Usage: node run.mjs [reps]   (writes results.json next to this file)
import { writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';
import { build } from 'esbuild';
import { chromium } from 'playwright';

const here = dirname(fileURLToPath(import.meta.url));
const reps = Number(process.argv[2] ?? 3);
const effects = ['confetti', 'emoji', 'balloons'];
const counts = [50, 500, 2000];

await build({
  entryPoints: [join(here, 'page/app.jsx')],
  outfile: join(here, 'page/app.js'),
  bundle: true,
  minify: true,
  jsx: 'automatic',
  define: { 'process.env.NODE_ENV': '"production"' },
});

const intervals = (frames) => frames.slice(1).map((t, i) => t - frames[i]);
const median = (xs) => {
  const s = [...xs].sort((a, b) => a - b);
  const m = s.length >> 1;
  return s.length % 2 ? s[m] : (s[m - 1] + s[m]) / 2;
};
const pct = (xs, p) => {
  const s = [...xs].sort((a, b) => a - b);
  return s[Math.min(s.length - 1, Math.floor((p / 100) * s.length))];
};
const metric = (m, name) => m.metrics.find((x) => x.name === name).value;

const browser = await chromium.launch({
  headless: false,
  args: [
    '--window-size=1280,860',
    '--disable-backgrounding-occluded-windows',
    '--disable-renderer-backgrounding',
    '--disable-background-timer-throttling',
  ],
});
const context = await browser.newContext({ viewport: null });
const results = { browser: browser.version(), reps, runs: [] };

for (const type of effects) {
  for (const count of counts) {
    const page = await context.newPage();
    const url = pathToFileURL(join(here, 'page/index.html'));
    url.search = `type=${type}&count=${count}`;
    await page.goto(url.href);
    await page.bringToFront();
    await page.waitForTimeout(1500); // let the new window reach the screen before measuring
    const cdp = await context.newCDPSession(page);
    await cdp.send('Performance.enable');

    const idle = intervals(await page.evaluate(() => window.__idle(1000)));
    const refreshMs = median(idle);
    if (refreshMs > 34) throw new Error(`rAF throttled (${refreshMs.toFixed(1)}ms); is the window hidden?`);

    await page.evaluate(() => window.__run()); // warm-up, not recorded

    for (let rep = 0; rep < reps; rep++) {
      await page.waitForTimeout(300);
      const m0 = await cdp.send('Performance.getMetrics');
      const frames = await page.evaluate(() => window.__run());
      const m1 = await cdp.send('Performance.getMetrics');
      const iv = intervals(frames);
      const durationMs = frames.at(-1) - frames[0];
      const delta = (name) => (metric(m1, name) - metric(m0, name)) * 1000;
      const run = {
        type,
        count,
        rep,
        refreshMs,
        durationMs,
        frames: iv.length,
        fps: (iv.length / durationMs) * 1000,
        p95FrameMs: pct(iv, 95),
        maxFrameMs: Math.max(...iv),
        droppedPct: (iv.filter((x) => x > refreshMs * 1.5).length / iv.length) * 100,
        scriptMs: delta('ScriptDuration'),
        styleMs: delta('RecalcStyleDuration'),
        layoutMs: delta('LayoutDuration'),
        taskMs: delta('TaskDuration'),
      };
      results.runs.push(run);
      console.log(
        `${type.padEnd(8)} ${String(count).padStart(5)} #${rep}  ${run.fps.toFixed(1)} fps  p95 ${run.p95FrameMs.toFixed(1)}ms  ` +
          `script ${run.scriptMs.toFixed(0)}  style ${run.styleMs.toFixed(0)}  layout ${run.layoutMs.toFixed(0)}  task ${run.taskMs.toFixed(0)}  (${run.durationMs.toFixed(0)}ms)`,
      );
    }
    await page.close();
  }
}

await browser.close();
writeFileSync(join(here, 'results.json'), JSON.stringify(results, null, 2));
```
