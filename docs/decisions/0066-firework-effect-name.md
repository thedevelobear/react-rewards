# 0066. The fireworks effect is named `firework`

- **Status:** Proposed
- **Date:** 2026-10-24

The folder is `src/effects/firework/`, the export `firework`, the config type `FireworkConfig` and the effect's `name` `'firework'`. `src/index.ts` exports `firework` and the type `FireworkConfig`. Display text, such as the site's "Fireworks", isn't covered.

**Why:** Effect names are singular, with no exceptions ([ADR 0037](0037-balloon-effect-name.md)).
