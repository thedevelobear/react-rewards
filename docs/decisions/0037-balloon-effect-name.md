# 0037. The balloons effect is named `balloon`

- **Status:** Accepted
- **Date:** 2026-10-23

The folder is `src/effects/balloon/`, the export `balloon`, the config type `BalloonConfig` and the effect's `name` `'balloon'`. The singular-name rule applies to effects with no exceptions. Display text on the site isn't covered.

**Why:** Folders and exported names are singular (plan, naming rule 2), and `confetti` and `emoji` already follow it.

**Consequences:** v2's `balloons` export becomes `balloon`.
